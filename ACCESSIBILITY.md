# Accessibility Statement

This site aims to conform to WCAG 2.1 AA.

## Measures
- Semantic HTML landmarks and headings.
- Alt text on meaningful images.
- Keyboard-navigable interactive elements.
- Sufficient color contrast for text.

## Feedback
Found an accessibility barrier? Open a GitHub issue and we will address it.

## Known limitations
- Some third-party embeds may not fully meet contrast requirements.
- Animations respect `prefers-reduced-motion` where supported.
