# Contributing

Thanks for your interest in improving this portfolio site!

## Workflow
1. Fork the repo and create a feature branch (`feat/your-change`).
2. Keep commits small and descriptive.
3. Run `npm run format` before opening a PR.
4. Open a PR against `main` and link any related issue.

## Code style
- Prettier config lives in `project-config/.prettierrc`.
- Prefer semantic HTML and accessible markup.

## Reporting bugs
Open an issue with steps to reproduce, expected vs. actual behavior, and browser/OS.

## Commit messages
Use imperative mood and a concise subject line:

```
Add dark-mode toggle to navbar
Fix broken project links on mobile
```

Reference issues with `#<number>` when applicable.
